Curriculum

Nine live classes, three weeks, one finished website.

What You Will Learn

Nine classes across three weeks, from your first tag to a finished website.

WEEK 1

The Foundations

Class 1: Introduction to Web Development

  • What web development is
  • How websites work
  • HTML, CSS, and JavaScript
  • Setting up the coding environment

Class 2: HTML — Building the Structure

  • HTML tags and elements
  • Headings, paragraphs, images, links, and lists

Class 3: HTML — Complete Webpages

  • Forms
  • Semantic HTML
  • Organizing website content
WEEK 2

Making It Beautiful

Class 4: CSS — Styling Your Website

  • Colors, fonts, backgrounds, spacing, borders, and shadows

Class 5: CSS — Layout and Responsive Design

  • Flexbox
  • Website layouts
  • Responsive design for mobile and desktop

Class 6: JavaScript — Adding Interactivity

  • Variables
  • Functions
  • Events
  • Basic DOM manipulation
WEEK 3

AI & Real Projects

Class 7: Using AI to Improve Your Coding Skills

  • Using AI to understand code
  • Debugging
  • Improving website designs
  • Learning to use AI responsibly

Class 8: Final Project

  • Build a simple personal portfolio, business website, restaurant website, school webpage, or other beginner-friendly website

Class 9: Project Showcase & Q&A

  • Present projects
  • Ask questions
  • Receive feedback

What Will You Be Able to Do?

  • Write basic HTML and CSS.
  • Understand the fundamentals of JavaScript.
  • Build a simple responsive website.
  • Use AI tools to assist with coding.
  • Create and present their own website project.
  • Understand the basics of how websites are built.
