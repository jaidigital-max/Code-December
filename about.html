What Is Code This December?

Code This December is a beginner-friendly December web development bootcamp designed for students who want to use their holiday productively by learning a valuable digital skill.

Through live online classes, practical exercises, and guided projects, students will learn the fundamentals of building websites — even if they have never written a line of code before.

  • Designed for secondary school and university students.
  • Suitable for complete beginners.
  • Online live training.
  • Practical learning approach.
  • Affordable December promotional fee.
